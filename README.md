Nokia Lumia 930
=============
This branch is for building LineageOS (or Android Q 10.0 AOSP based roms) ROMs.

<img src="https://fdn2.gsmarena.com/vv/pics/nokia/nokia-lumia-930-1.jpg" width="410" height="550" />

Basic   | Spec Sheet
-------:|:-------------------------
CPU     | Qualcomm Snapdragon 800 (MSM8974VV)
GPU     | Adreno 330
Memory  | 2GB LPDDR3 RAM
Shipped OS | Windows Phone 8.1
Storage | 32GB (Samsung/Toshiba)
Battery | 2420 mAh (BV-5QW), non-removable
Touch   | Synaptics
Display | 5.0" AMOLED 1080 x 1920 px (~441 ppi)
Rear Camera| 20 MP PureView, OIS, ZEISS optics |
Front Camera | 1.2 MP |

Variants
=============
The following variants share a similar hardware platform.
Compatibility may vary between models.

| Device Type | Codename | Device Model | Status |
|:------------|:---------|:-------------|:-------|
| RM-1045 | martini | Nokia Lumia 930 | Booting |
| RM-1087 | martini | Nokia Lumia 930 | Untested |
| RM-927 | TBD | Nokia Lumia Icon (929) | Untested |

**Note:** The Lumia Icon (RM-927) shares most of its
hardware with the Lumia 930, but compatibility
has not yet been verified on real hardware.
